  - Pastilles de la carte : Vide, En panne et En service distingués par la seule couleur — `js/summaries.js:95`, `css/overlays.css:2041`

## But
Sur la carte, une pastille **Vide** porte un petit signe « − » et une pastille **En panne** un signe « ! »,
dans un rond de 18 px en bas à droite (le haut à droite reste au cœur des favoris). Une personne qui
distingue mal l'orange du rouge reconnaît l'état sans ouvrir la fiche. Rien d'autre ne change.

## User story
En tant que testeur qui distingue mal les couleurs, je veux reconnaître Vide et En panne sur la carte,
afin de savoir où aller sans ouvrir chaque fiche.

**Critères d'acceptation**
- [ ] Pastille Vide : un rond orange `#EA580C` cerclé de blanc, signe « − » (U+2212) blanc, en bas à droite.
- [ ] Pastille En panne : même rond en rouge `#DC2626`, signe « ! ».
- [ ] En service et Pas d'info : aucun signe (l'anneau qui se remplit et le pointillé gris suffisent).
- [ ] Un favori vide ou en panne garde son cœur en haut à droite **et** prend le signe en bas à droite.
- [ ] La liste latérale ne change pas (elle écrit déjà « Vide » / « En panne ») ; l'anneau et ses couleurs ne changent pas.
- [ ] Le signe est `aria-hidden="true"` : le titre de la pastille (« Nom : Vide ») reste l'information lue.

   `return \`<svg class="${className}" viewBox="0 0 44 44" aria-hidden="true">${track}${fill}</svg>\`;` et son `}`).
   Avant :
   ```js
       return `<svg class="${className}" viewBox="0 0 44 44" aria-hidden="true">${track}${fill}</svg>`;
   }
   ```
   Après :
   ```js
       return `<svg class="${className}" viewBox="0 0 44 44" aria-hidden="true">${track}${fill}</svg>`;
   }

   // A11Y-03 : Vide et En panne se reconnaissent aussi sans la couleur (WCAG 1.4.1) : un petit
   // signe en bas a droite de la pastille de la carte (decision Stephane 2026-11-10). En service
   // et Pas d'info : rien (anneau qui se remplit, pointille). La liste ecrit deja le mot.
   const STATUS_SIGNS = { empty: '−', broken: '!' };

   export function renderStatusSign(summary) {
       const sign = STATUS_SIGNS[summary?.state];
       return sign ? `<span class="distributor-pin-sign is-${summary.state}" aria-hidden="true">${sign}</span>` : '';
   }
   ```

## Pièges connus
- « − » est U+2212 dans `js/summaries.js` ; dans les tests, écrire `−` (comme dans le code fourni) pour ne pas
  confondre avec un tiret.

  `${fav}${renderStatusSign(summary)}</div>\``, avec un petit script Node (fichiers en CRLF, pas de `sed -i`).
