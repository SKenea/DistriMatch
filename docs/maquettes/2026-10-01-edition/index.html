Modifier une fiche sans bouton : trois pistes

Plus de bouton « Modifier » ni de mode édition : on agit directement sur les produits. Trois gestes à comparer pour les trois actions : changer la dispo, ajouter, retirer (toujours rattrapable par « Annuler »). Chaque maquette a une pastille « Réglages de la maquette » (visiteur / connecté, avec ou sans produit, réinitialiser).

Piste 1

Toucher pour changer

On garde la grille de cartes. L'étiquette d'une carte est le contrôle : la toucher déplie « Dispo / Pas dispo » sur la carte même, façon « Toujours là ? » de Waze. Toucher le nom le renomme ; une carte fantôme « + Ajouter un produit » en fin de grille.

Signaler : Retirer : vider le nom, ou appui long -> « Renommer / Retirer ». Toast « Annuler » 7 s. Prix : toucher « €€ ».

Pour
Benchmark 9/10 : tout se fait d’un simple tap, découvrable, accessible, on garde la fiche actuelle.
Contre
Deux taps pour signaler (ouvrir, choisir) ; c’est voulu : ça permet aussi de confirmer un « Dispo ».

Piste 2

Glisser

Les produits passent en liste pleine largeur. Glisser une ligne à droite = Dispo (fond vert), à gauche = Pas dispo (fond gris). Une ligne vide en bas pour ajouter, façon Rappels.

Signaler : Toucher la ligne ouvre aussi les deux réponses (alternative obligatoire au geste). Retirer : appui long. Démo animée au premier affichage.

Pour
Le plus rapide pour qui connaît le geste : un seul mouvement.
Contre
Benchmark 5/10 : geste caché (peu de gens glissent sans y penser), conflit possible avec le défilement, quitte la grille de cartes.

Piste 3

Liste à cocher

Une liste de courses : une grande case ronde par produit, cochée verte = Dispo, vide = Pas dispo, pointillée = Pas d'info. Ligne vide en bas pour ajouter en enchaînant, nom modifiable en place.

Signaler : Retirer : glisser à gauche (seul glissement), ou vider le nom, ou appui long. Toast « Annuler ».

Pour
Benchmark 7/10 : ultra familier (Rappels, Keep), un seul tap pour signaler.
Contre
Quitte la grille de cartes ; reconfirmer un « Dispo » ancien demande deux taps ; une case = deux états seulement.

Ce que dit le benchmark

Sources : NN/g (gestes contextuels, confirmation vs annulation), WCAG 2.2, Apple HIG, Material, Rappels, Keep, Todoist, Gmail, Waze.

Recommandation du benchmark : la piste 1 (toucher), en lui empruntant la ligne vide qui enchaîne les ajouts de la 3. Le signal devant le distributeur, le geste le plus fréquent, reste un toucher direct sur l'étiquette.

Tu peux choisir une piste telle quelle ou en mélanger deux (par exemple « le toucher de 1 avec la ligne vide de 3 »). Ensuite : reformulation, epic, puis implémentation dans l'app.
